# Project management / 企业落地设计

本页是尚未实施的组织协作方案。以下职责与时程为设计建议，未验证团队协作、供应商交付或线上运营效果。

## RACI

R=执行，A=最终负责，C=咨询，I=知会。每项一个 A，避免“所有团队都负责”。

| 决策/产物 | 产品/训练策略 | 算法 | 数据工程 | 标注运营 | 安全/领域专家 |
|---|---|---|---|---|---|
| 用户问题→能力与成功指标 | A/R | C | I | C | C |
| 数据/评测 spec 与切片权重 | A | R | C | C | C |
| 冻结测试集与污染规则 | A | R | R | C | C |
| 清洗、生成、版本与去重 | C | C | A/R | C | C |
| 标注手册、抽检与仲裁 | C | C | C | A/R | R |
| 小规模训练、消融与资源预算 | C | A/R | R | I | C |
| 自动评测与回归报告 | A | R | R | C | C |
| 发布/停止与风险接受 | A/R | C | I | I | C |

## 里程碑与退出标准

| 阶段 | 可检查交付 | 退出条件 |
|---|---|---|
| M0 问题定义 | 产品 brief、非目标、指标及风险清单 | 能力与实际任务失败有明确联系 |
| M1 数据合同 | schema、Data Card、版本、分组 split | 样本可重建、无跨集同图、标签可审计 |
| M2 评测合同 | adapter、解析、逐条指标、错误分类 | 已知错误控制能被检测；异常不丢分母 |
| M3 生产试点 | 可解释队列、增强与人工抽检 | 标签与来源合格；预算约束有效 |
| M4 小实验 | 对照组、固定预算、独立测试集 | 支持/不支持假设都有明确下一步 |
| M5 回归决策 | 全任务与安全切片、版本差异 | 重要能力不退化；证据完整才能发布 |

本仓库 M0–M3 的自动化部分已实现；M4 是规则对照，不是训练；M5 验证了拒绝逻辑，不代表真实模型发布。真实模型训练、供应商验收与线上灰度尚未执行。

## 风险登记表

| 风险 | 触发信号 | 负责人角色 | 处置 |
|---|---|---|---|
| 测试集被回流污染 | 同 family/hash 跨 split | 数据工程 | 阻断构建、重分版本，不只删除一条 |
| 标签与生成器共同出错 | 手写/视觉检查不一致 | 评测/领域专家 | 先冻结生产、定位 oracle/renderer |
| 热门错误挤占预算 | 队列同模板占比过高 | 产品 | diversity cap、随机探索样本、重新设权重 |
| 总分掩盖重要切片退化 | 任一关键能力下降 | 产品/算法 | 拒绝候选；先修复或重新预注册容差 |
| 成本或供应商质量失控 | 接受率下降、返工增加 | 标注运营 | 小批试单、停止扩量、仲裁 |
| API 错误被当成模型错误 | 超时/429上升 | 数据工程 | 分离系统指标；有界重试；不删失败样本 |
| 高相似合成数据不迁移 | 合成集升高，真实任务不变 | 算法 | 新冻结真实任务测试；停止宣传合成收益 |

## 标注与供应商质量管理（方案）

先提供操作定义、正反例、边界案例、冲突仲裁规则，再进行小批资格测试。试点可以把 10% 随机样本双人盲标，并对安全关键/不一致样本全部复核；10% 是起始预算建议，不是实验事实。同时看每类准确率、分歧率、返工率与单位最终合格样本成本，不能仅看交付量和自报一致率。隐藏 gold 必须可靠且避免泄露；周期性轮换。

用随机审计防止只抽“看起来容易”的样本，用任务/难度分层防止平均通过率遮掩罕见错误。确认受控处理、访问权限、留存与删除协议；敏感数据不进入公开仓库。批次未通过时拒收或返工，不把噪声数据静默混入训练。
