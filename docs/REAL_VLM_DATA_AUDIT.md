# 图像与泄漏检查

旧 `tabletop-v1` 保留不变：o1 的构造、属性和目标存在关联，o1/o2 字符还增加 OCR 负担；六任务规则适配器读取 metadata。因此不将原得分当成 VLM 表现，也不把旧样本直接重新划分后宣称新保留集。

新 `visual-tabletop-v2` 使用 seed 91027，24 个独立场景族，每族一张图及三道题。先划分族 0–11 为 dev、12–23 为 holdout，再生成随机场景。A–D 独立打乱，目标颜色/形状独立采样，空间题随机选择两个不同 ID。没有针对正确答案生成文字、文件名标签或可读答案水印。文件名也不传入模型。标题是所有图片共有的画布尺寸。

自动核对样本 ID 唯一、族与图像哈希不跨集、实际图像 SHA-256 不变。全 24 张接触表已视觉检查：四物体无重叠，A–D 显示清晰，颜色形状与图形一致；这属于作者/AI 辅助检查，并非独立双人盲标。标签由生成状态构造，存在生成器与标签共同错误风险。

空间题定义为严格比较中心 x 坐标。部分同列物体中心仅相差少量像素，是几何定义明确但视觉辨别困难的边界题；保留全部题，不依结果删除。`diagnostics.json` 报告 |dx|<25 像素切片。四物体及共享模板限制了泛化范围；按族隔离不等于跨生成器/真实场景 OOD。

开发集增强仅对答错且格式合法样本取最多六个不同父族，做整图物体平移 (+5,-5)。颜色、形状、相对 x 顺序均不变，标签继承有明确不变性依据。保存 parent_id、父图哈希、配置、标签来源、子图哈希与新数据版本。增强仍属于父开发族，不能进入保留集；没有实际训练，不存在已验证的模型能力收益。
