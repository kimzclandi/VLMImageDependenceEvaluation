# 视觉贡献实验：面试验收

## 30秒介绍

旧VLM实验的61.1%保留集准确率被答案先验追平，所以我没有把它写成视觉能力。我新建答案平衡、无文字ID的反事实场景族，冻结协议后比较真实、空白和错配图像，保存270次真实CPU生成，按场景族做配对统计。输出变化只是敏感性，只有正确率改善才支持图像贡献；实际保留集宏平均54.7%对空白40%，贡献主要来自空间题；所有结论限于这个小型合成分布，无训练收益声明。

## 2分钟讲解

第一步判断测量是否有效：题面不传gold、metadata或文件名，去掉OCR对象ID，空间中心留大间距。dev与holdout各15场景族，同一族的所有反事实一起划分；三种任务在各自答案域内均匀覆盖，因此常数答案基线明确。

第二步固定干预。每题保持问题、模型、prompt和评分gold不变，只换真实图、白图或同族答案不同的错配图。错配图自己的答案另存，不能在评分时换成donor gold。主指标为三任务等权的真实−空白准确率差，额外看错配、格式合法率、修复/退化和原始输出改变。族级bootstrap避免把同布局变体当独立样本。

第三步从结果作有限决策。若没有贡献，不通过换模型/提示反复追正结果，也不机械生成更多平移。若有贡献，也只能证明这个设置下图像帮助答对；固定尺寸圆允许像素面积捷径，不能证明通用计数机制。实际结果见本轮报告。

## 最强质疑

- **真实比空白高就是视觉推理吗？** 只支持输入图像对当前任务准确率有帮助；无法定位机制，也不证明组合推理或道路泛化。
- **计数题是否有捷径？** 有，红色面积与数目相关。排除了题面/ID/文件名泄漏，没有排除所有视觉捷径，不能夸大。
- **空白和错配为什么都需要？** 空白估计无有效场景时的题面/答案先验，错配检查对不同内容是否响应；二者分布都不同，不能把任一个单独视为所有视觉因果性的证明。
- **为什么不用每题独立bootstrap？** 同族共享布局，独立抽题会高估样本量。每任务只有五个holdout族，区间粗。
- **失败是不是“感知错误”？** 只是症状。图像干预能缩小解释，但表征、指令理解、输出偏置等原因仍竞争存在，没有人工确认。

## 现场必须解释或修改

`grounding.py::build`（平衡构造、派生/错配）、`audit`（血缘与像素完整性）、`score`（全分母和原gold）、`summarize`（任务权重与配对族bootstrap）；`local_vlm.py::VisualInput/LocalVLM.predict`（像素接口、processor、生成与文本切片）。输入是图像bytes与字符串；processor产生带batch维的token和视觉张量，生成输出只解码输入token之后的部分。

工程检查：先确认哪个证据轨道；核对protocol与源代码/处理器摘要；数出90×3；用空/错输出验证分母；查看错配gold不同；重算先验；解释不做VLM训练的原因。
