# 视觉输入干预方法

对同一问题分别输入原图、空白图与错配图，固定提示、模型及评分规则，比较视觉输入变化与输出变化。错配图的供体答案不替代原问题参考答案。

全量包含 90 个问题、30 个场景族，共 270 次推理；保留集为 45 个问题、15 个场景族。按场景族统计不确定性，避免把同族问题当作独立图像。总准确率与任务宏平均分开报告，保留每个任务的分母。

模型输入排除文件名、标签及参考答案。接口约束用于防止意外泄漏，不构成安全沙箱。原图优于空白图或错配图只能支持本实验条件下的视觉敏感性，不能证明通用视觉推理能力；合成图像中的面积等捷径仍是竞争解释。

当前结果、切片与限制见 [实验报告](GROUNDING_V3_REPORT.md)，证据以保存的逐条预测和冻结协议为准。没有模型训练或生产效果验证。代码与文档使用 AI 辅助开发。
