# 历史规则流水线说明

本页对应早期 metadata 规则演示，真实 VLM 推理见 [实验报告](REAL_VLM_EXPERIMENT.md) 和 [复现说明](REAL_VLM_REPRODUCE.md)。

规则流程生成 240 条桌面多模态样本，从开发集选出 18 个父样本并生成 108 条增强数据。评测、失败分类、样本优先级、数据生产和版本门禁通过可追溯记录连接。

规则可以读取结构化场景信息，因此其结果不能与仅接收图像和问题的神经模型公平比较。历史候选版本虽然总分上升，计数切片出现退化，门禁结果为 `REJECT`。增强数量和规则分数变化不代表模型训练收益；该流程未训练神经模型。

原始结果见 [历史报告](EXPERIMENT_REPORT.md)，当前研究入口见 [研究索引](RESEARCH_INDEX.md)。代码与文档使用 AI 辅助开发。
