# 真实 VLM 配对评测方法

固定模型接收图像与问题，模型输入不包含参考答案或场景 metadata。协议按场景族隔离开发集与保留集；同一图片配对比较两种提示，保存原始生成文本、严格解析结果和失败分母。

本轮共 72 个问题、24 个场景族，两种提示产生 144 次 CPU 推理。保留集两种提示均为 22/36，与答案先验基线同分，因此不能由总分推断模型使用了视觉信息。

失败分类描述可观察症状，不确证视觉、OCR 或推理根因。只有开发集失败进入增强流程；增强样本可追溯到父样本，但本轮没有训练或增强收益验证。

实验数据见 [报告](REAL_VLM_EXPERIMENT.md)，命令见 [复现说明](REAL_VLM_REPRODUCE.md)，视觉输入干预见 [后续方法](GROUNDING_V3_METHOD.md)。代码与文档使用 AI 辅助开发。
