# 真实 SmolVLM 桌面视觉实验：观察提示未带来保留集收益

## 结论

本机 CPU 完成 **144 次真实模型生成**。新保留集 36 题、12 场景族：基础提示和观察提示都答对 **22/36（61.1%）**。观察提示修复 1 题、退化 1 题，未支持“显式观察提示提高视觉判断”的假设。没有继续试提示，没有训练模型。

这是图像加问题驱动的真实推理，但当前实验**不能证明模型优于答案先验**：只用开发集确定各任务多数答案（计数 1、存在 no、空间 no），在保留集也得到 22/36。此为结果分析时增加的描述性先验检查，不是预注册主对照，也没有用它调整模型。未来需在新冻结版本中做答案平衡与图像消融；不能凭本次准确率宣称已证明视觉 grounding。

## 协议与来源

协议在 commit `b9f9bd0`、任何模型输出之前冻结；见 `reports/real_vlm/protocol.json`。模型固定 `HuggingFaceTB/SmolVLM-256M-Instruct` revision `7e3e67edbbed1bf9888184d9df282b700a323964`，Apache-2.0。本地权重 SHA-256 与官方 LFS 记录一致：`74dea5904032e5ae99a2e0eef5179e6ac0f1dedc3ab0c7c2a5d4d387c843203e`。

新 seed 91027、24 场景族，先分组再生成，每族三题。与历史规则样本分目录，模型接口只有图像字节与问题。每个样本交替运行 baseline/observe，相同图像、模型、生成长度 16、自由贪心解码和严格解析器。既没有 gold 解码候选，也没有有限答案 trie。冻结后补充官方权重哈希断言属于身份核验，不改变已运行提示、图片或生成参数。

## 实际结果

| 集合 / 指标 | 基础提示 | 观察提示 |
|---|---:|---:|
| dev 总体 | 18/36 = 50.0% | 19/36 = 52.8% |
| holdout 总体 | 22/36 = 61.1% | 22/36 = 61.1% |
| holdout 计数 | 7/12 = 58.3% | 8/12 = 66.7% |
| holdout 属性存在性 | 8/12 = 66.7% | 7/12 = 58.3% |
| holdout 空间 | 7/12 = 58.3% | 7/12 = 58.3% |
| dev 格式合法 | 36/36 = 100% | 34/36 = 94.4% |
| holdout 格式合法 | 36/36 = 100% | 35/36 = 97.2% |

系统异常 0 次；所有生成输出均保留。失败 63 条是“样本 × 提示”记录数，不是 63 张独立图片。缺失/异常/解析失败均保留分母。共同格式合法的 holdout 子集为 35 题，两臂同为 22/35 = 62.9%；这只是描述性条件子集，不能取代全分母主指标。

后验描述性场景族 bootstrap（2,000 次、seed 42）得到 holdout 总体差值区间 [0,0]：本轮一修复一退化恰好在同一族中，每个族的总差值均为零。**这不代表两方法总体等效或没有不确定性**，只是这个很小的经验分布无法呈现族内抵消之外的差异。不能用这个退化区间作推广保证。

## 失败、数据质量与生产

`review_queue.jsonl` 保存所有错误的原始文本、标签、预测、可观察症状、`root_cause=unverified`、`review_status=pending`。语义误答不能直接认定感知或 OCR 根因；格式错误也不能直接认定视觉能力差。

只从 dev 的格式合法误答中，按固定顺序取最多 6 个不同父族生成全局平移 (+5,-5) 变体。每个子样本保存父 ID/哈希、生成配置、标签、数据版本、子图哈希，且保持相对位置和颜色形状标签。它们是待进一步复核的数据生产产物，**未训练、未验证训练收益**。

[数据审计](REAL_VLM_DATA_AUDIT.md) 记录全图检查。空间边界切片 |dx|<25 像素为 dev 5 题、holdout 3 题，holdout 两提示均 2/3；未删除或修订这些题。保留集计数标签只有 0 和 1（3/9），缺少 2–4；存在性 no/yes 为 8/4。这些分布偏差明显限制实验效力，不能把模型分数等同于广泛计数能力。
