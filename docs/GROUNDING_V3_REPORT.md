## 反证与解释

贡献主要来自空间题（90%对50%）；存在题没有增益，计数24%仍接近20%先验。真实图帮助答对与输出对图敏感是不同命题，不能仅凭变化题数推断grounding。当前通过判据只支持这些合成任务中的视觉输入价值；固定物体尺寸还允许面积计数捷径。v2与v3数据分布不同，61.1%与44.4%不能直接解释成模型能力涨跌。

同族变体一起抽样，15个holdout族而非45个独立场景。每任务仅5族，跨集合共享生成器；不是道路数据、OOD、组合泛化或真机证据。格式合法率也不能替代语义准确率。
